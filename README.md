# Олег AI

Свой ИИ-чат: регистрация и вход, админ-панель, лёгкие модели (Ollama), озвучка (Piper) со своим голосом, веб-поиск, который модель вызывает сама. Работает на ПК, iOS и Android (адаптивно + можно добавить на экран «Домой»). Без npm-зависимостей, нужен Node 22.13+.

## Установка (Ubuntu/Debian, нужен sudo)
```bash
git clone https://github.com/<you>/oleg-ai.git && cd oleg-ai
sudo ./install.sh
```
Открой `http://<IP>:3000`, зарегистрируйся — **первый пользователь становится админом**. Далее ⚙ → Модели → установить `qwen2.5:3b` (или другую) → «Выбрать».
Для https поставь Caddy/nginx перед портом 3000 и включи `COOKIE_SECURE=1` в `/opt/oleg-ai/.env`.

## Под любое железо
Сервер сам определяет мощность и выбирает профиль (⚙ → Сервер, можно сменить вручную):
| Профиль | Железо | Модели | Контекст / история | Поиск |
|---|---|---|---|---|
| Мини | 1 ядро, 2 ГБ, 10 ГБ диск | qwen2.5:0.5b, qwen2.5:1.5b, llama3.2:1b | 2048 / 8 | на каждый вопрос (слабые модели сами не вызывают инструменты) |
| Средний | 2 ядра, 4 ГБ | qwen2.5:3b, llama3.2:3b, qwen3:4b | 4096 / 14 | модель решает сама |
| Полный | 4 ядра, 8 ГБ, 150 ГБ | qwen2.5:7b, qwen3:8b, llama3.1:8b | 8192 / 30 | модель решает сама |

`install.sh` на сервере с <3,3 ГБ RAM добавляет swap 2 ГБ и ограничивает Ollama одной моделью в памяти. Все значения профиля правятся в админ-панели.

## Быстро на слабом сервере (профиль «Мини»)
Ответы печатаются сразу по мере генерации (стрим), кнопка «Стоп» останавливает модель и разгружает CPU. Короткий системный промпт и ограничение длины ответа, модель прогревается и держится в памяти (`keep 30m`), поиск запускается только когда вопрос этого требует, результаты поиска кэшируются, старая история обрезается, очередь запросов ограничена, Piper работает с низким приоритетом, Node ограничен по памяти, Ollama — одна модель и квантованный кэш. Лучший баланс ума и скорости для 1 ядра/2 ГБ — `qwen2.5:1.5b`; `install.sh` скачивает модель под твоё железо сам.

## Обучение
Админ-панель → Обучение. **База знаний** (текст или файл; Олег находит нужное и опирается на это), **обратная связь** 👍/👎 в чате (при авто-обучении 👍-ответы сразу попадают в базу) и **экспорт датасета** JSONL для настоящего дообучения на мощной машине. Дообучение весов на сервере 1 ядро/2 ГБ невозможно физически.

## Свой интерфейс
Админ-панель → Интерфейс: расположение чата, панели статуса, строки ввода и кнопок (порядок и видимость), все тексты сайта, цвета, размер шрифта, прозрачность, свой аватар и фон, свой CSS. «Сбросить» возвращает стандарт.

## Музыка
Админ-панель → Музыка: загрузи треки (mp3/ogg/wav/m4a/flac). Они играют по кругу при входе на сайт; во время озвучки ответа и голосового ввода музыка плавно затихает и так же плавно возвращается. Громкость, уровень при озвучке и плавность настраиваются, у каждого пользователя есть кнопка ♪ (вкл/выкл). Браузеры не дают играть звуку до первого касания страницы — тогда музыка стартует с первого тапа.

## Файлы и страницы
Скрепка в чате: текст, код, CSV, JSON, PDF (нужен `pdftotext`), DOCX, XLSX, PPTX. Сканы и картинки без текстового слоя не читаются (нет OCR). Модель также сама открывает страницы по ссылкам (`open_url`), приватные адреса заблокированы.

## Обновление
- **Через GitHub:** `cd oleg-ai && sudo ./update.sh`
- **Через админ-панель, без скриптов:** на своём компьютере `npm run build-update "что нового"` → получится `dist/oleg-ai-<версия>.oleg` → ⚙ → Обновление → загрузить файл. Перед установкой делается бэкап (`data/backups`), сервер перезапускается сам. Не забудь поднять `version` в `package.json`.

### Формат `.oleg`
Это `tar.gz`: `manifest.json` (`{app:"oleg-ai", version, notes, files:{путь: sha256}}`) + папка `payload/` с файлами. Сервер проверяет имя приложения, суммы sha256 и запрещает пути вне проекта и в `data/`.

## Голос
Админ-панель → Голос: выбери голос или загрузи свой — пару файлов Piper `имя.onnx` + `имя.onnx.json`. Без голоса используется озвучка браузера.

## За reverse proxy (Caddy/nginx)
В `/opt/oleg-ai/.env` добавь `TRUST_PROXY=1` (чтобы лимит попыток входа считался по реальному IP, а не по IP прокси) и `COOKIE_SECURE=1` при https. В nginx для чата отключи буферизацию (`proxy_buffering off;`). Если запускаешь без systemd (`npm start`), после обновления из админ-панели сервер нужно поднять вручную: он сам завершается.

## Безопасность
Пароли — scrypt, сессии — HttpOnly cookie, лимит попыток входа, загрузки и модели — только админу. Файл `.oleg` может менять код сервера: ставь только свои сборки.
