# Олег AI

Свой ИИ-чат: регистрация и вход, админ-панель, лёгкие модели (Ollama), озвучка (Piper) со своим голосом, веб-поиск, который модель вызывает сама. Работает на ПК, iOS и Android (адаптивно + можно добавить на экран «Домой»). Без npm-зависимостей, нужен Node 22.13+.

## Установка (Ubuntu/Debian, нужен sudo)
```bash
git clone https://github.com/<you>/oleg-ai.git && cd oleg-ai
sudo ./install.sh
```
Открой `http://<IP>:3000`, зарегистрируйся — **первый пользователь становится админом**. Далее ⚙ → Модели → установить `qwen2.5:3b` (или другую) → «Выбрать».
Для https поставь Caddy/nginx перед портом 3000 и включи `COOKIE_SECURE=1` в `/opt/oleg-ai/.env`.

## Обновление
- **Через GitHub:** `cd oleg-ai && sudo ./update.sh`
- **Через админ-панель, без скриптов:** на своём компьютере `npm run build-update "что нового"` → получится `dist/oleg-ai-<версия>.oleg` → ⚙ → Обновление → загрузить файл. Перед установкой делается бэкап (`data/backups`), сервер перезапускается сам. Не забудь поднять `version` в `package.json`.

### Формат `.oleg`
Это `tar.gz`: `manifest.json` (`{app:"oleg-ai", version, notes, files:{путь: sha256}}`) + папка `payload/` с файлами. Сервер проверяет имя приложения, суммы sha256 и запрещает пути вне проекта и в `data/`.

## Голос
Админ-панель → Голос: выбери голос или загрузи свой — пару файлов Piper `имя.onnx` + `имя.onnx.json`. Без голоса используется озвучка браузера.

## Безопасность
Пароли — scrypt, сессии — HttpOnly cookie, лимит попыток входа, загрузки и модели — только админу. Файл `.oleg` может менять код сервера: ставь только свои сборки.
