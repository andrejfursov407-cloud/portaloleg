# Портал Олега Борисовского

Закрытый сайт: вход только после регистрации и авторизации. Внутри видео, фото, музыка, блог, админ-панель
и чат с локальной нейросетью «Олег AI». Нейросеть работает на вашем сервере через [Ollama](https://ollama.com),
данные никуда не отправляются, API-ключи не нужны.

## Возможности

- Регистрация и вход, без авторизации доступ к странице и к файлам закрыт (пароли хранятся в виде хешей scrypt).
- Дизайн в стиле скриншота: шапка, главное фото, три карточки, новости; адаптация под телефоны и планшеты.
- Плееры: видео, аудио (по очереди), просмотр фото на весь экран со свайпом.
- Админ-панель (виден только администратору):
  - **Дизайн:** главное фото (положение для компьютера и телефона), цвета, тексты главной;
  - **Файлы:** загрузка видео, фото и аудио с прогрессом, удаление;
  - **Новости и тексты:** блог, страницы «Биография», «Проекты», «Контакты», ссылки на соцсети;
  - **Отчёт:** пользователи, активность, популярные разделы и файлы, история посещений, выгрузка в CSV;
  - **Нейросеть:** состояние Ollama, скачивание и удаление моделей, выбор модели, настройки ответов.
- «Олег AI»: чат, ответы приходят потоком, очередь запросов, дневной лимит на человека.

## Требования

Ubuntu 24.04 и права root. Рассчитано на сервер **6 ядер, 8 ГБ ОЗУ, 150 ГБ SSD** без видеокарты.

| Ресурс | Куда уходит |
|---|---|
| ОЗУ | модель `qwen3.5:4b` около 4–5 ГБ, сайт и nginx до 0,5 ГБ, остальное система; плюс 4 ГБ подкачки как страховка |
| Диск | система около 10 ГБ, модель 3–4 ГБ, остальное под ваши видео, фото и музыку |
| Процессор | ответ генерируется на ядрах процессора, ориентир для модели 4B: 5–10 слов в секунду (зависит от процессора) |

## Установка

Вариант 1: через клонирование.

```bash
git clone https://github.com/ПОЛЬЗОВАТЕЛЬ/РЕПОЗИТОРИЙ.git
cd РЕПОЗИТОРИЙ
sudo DOMAIN=example.com EMAIL=you@example.com ADMIN_EMAIL=you@example.com bash install.sh
```

Вариант 2: одной командой, без клонирования.

```bash
curl -fsSL https://raw.githubusercontent.com/ПОЛЬЗОВАТЕЛЬ/РЕПОЗИТОРИЙ/main/install.sh | \
  sudo REPO=ПОЛЬЗОВАТЕЛЬ/РЕПОЗИТОРИЙ DOMAIN=example.com EMAIL=you@example.com ADMIN_EMAIL=you@example.com bash
```

Репозиторий должен быть публичным (для закрытого используйте вариант 1). Без `DOMAIN` сайт откроется по IP-адресу по http.
Для HTTPS домен должен уже указывать на сервер.

Установка занимает 10–20 минут, основное время уходит на скачивание модели.

| Переменная | Назначение |
|---|---|
| `ADMIN_EMAIL` | почта администратора: кто зарегистрируется с ней, получит админ-панель. Если не задана, администратором станет первый зарегистрированный |
| `DOMAIN`, `EMAIL` | домен и почта для сертификата Let's Encrypt |
| `AI_MODEL` | модель Ollama. По умолчанию подбирается по памяти, для 8 ГБ это `qwen3.5:4b` |
| `SKIP_AI=1` | не ставить нейросеть |
| `SWAP_GB` | файл подкачки, если его нет (по умолчанию 4, `0` отключает) |
| `ALLOW_REGISTRATION` | `1` (по умолчанию) или `0`, чтобы закрыть регистрацию |
| `MAX_UPLOAD_MB` | максимальный размер одного файла, по умолчанию 2048 |
| `APP_DIR` | каталог установки, по умолчанию `/opt/portal` |

## После установки

1. Откройте сайт и зарегистрируйтесь с почтой `ADMIN_EMAIL` (вы станете администратором).
2. В админ-панели во вкладке «Дизайн» загрузите главное фото, настройте цвета и тексты.
3. Загрузите файлы во вкладке «Файлы», заполните «Новости и тексты».
4. Во вкладке «Нейросеть» проверьте связь. Другие модели скачиваются там же, кнопкой.

Если закрыть регистрацию (`ALLOW_REGISTRATION=0` в `/etc/portal.env`, затем `systemctl restart portal`),
новых посетителей вы будете добавлять сами: временно включите регистрацию.

## Нейросеть «Олег AI»

- Модель хранится на сервере: `/usr/share/ollama/.ollama/models`. Порт Ollama (11434) наружу не открыт.
- Одновременно отвечает на один вопрос, остальные ждут в очереди (до 8 человек). Если закрыть вкладку, генерация прекращается.
- Для 8 ГБ подходят модели до 4 млрд параметров (`qwen3.5:4b`, `gemma3:4b`, `llama3.2:3b`). Модель на 9 млрд параметров займёт почти всю память.
- Названия моделей в библиотеке Ollama меняются: если модель не скачивается, выберите другую в админ-панели.
- Инструкция по умолчанию говорит, что «Олег AI» не настоящий Олег Борисовский и не врач. Не убирайте эти оговорки.

## Приватность

В истории посещений хранятся адреса (IP), время и действия людей. Сообщите посетителям об этом
в политике конфиденциальности. Переписка с «Олег AI» на сервере не хранится, она остаётся в браузере пользователя.

## Обслуживание

```bash
journalctl -u portal -f        # логи сайта
journalctl -u ollama -f        # логи нейросети
systemctl restart portal       # перезапуск (также после правки /etc/portal.env)
sudo bash install.sh           # обновление кода (данные и файлы не трогаются)
```

Резервная копия: каталоги `/opt/portal/data` (пользователи, новости, настройки) и `/opt/portal/media` (файлы).

Забыли пароль или нужно назначить администратора (затем `systemctl restart portal`):

```bash
sudo -u portal node /opt/portal/server.js --passwd user@example.com НОВЫЙ_ПАРОЛЬ
sudo -u portal node /opt/portal/server.js --admin user@example.com
```

Удаление: `sudo bash uninstall.sh` (данные сохраняются), `--purge` удаляет и данные, `--with-ollama` удаляет Ollama и модели.

## Структура репозитория

```
app/            сайт: server.js (без зависимостей, нужен Node.js 18+), public/ и private/
deploy/         шаблоны systemd, nginx и настройки Ollama
tests/smoke.sh  быстрая проверка (npm test)
install.sh      установка и обновление
uninstall.sh    удаление
.github/        проверка при каждом push (GitHub Actions)
```

Локальный запуск для разработки: `npm start`, сайт на http://127.0.0.1:3000 (данные в `app/data`, файлы в `app/media`).

## Если что-то не работает

- **Страница не открывается:** `systemctl status portal nginx`, открыты ли порты 80 и 443 у хостинг-провайдера.
- **Нет HTTPS:** домен должен указывать на IP сервера до запуска установки; повторите запуск.
- **«Олег AI» отвечает медленно:** выберите модель поменьше (`qwen3.5:2b`) или уменьшите «Максимум токенов в ответе».
- **Не хватает памяти:** `free -h`; убедитесь, что включена подкачка, и выберите модель поменьше.
- **Файл не загружается:** проверьте `MAX_UPLOAD_MB` и формат (видео mp4/webm/mov, фото jpg/png/webp/gif, аудио mp3/m4a/ogg/wav/flac/aac).
